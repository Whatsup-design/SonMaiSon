
Build the frontend guild/group chat integration using the existing backend. Use VITE_API_BASE_URL from env as the backend base URL. After login, use data.session.accessToken from the backend login response as the Bearer token for every request and as the Socket.IO auth token.

Implement these API calls:

GET /guilds fetches all guilds the current user joined.

POST /guilds creates a guild. Body: { "name": "My Server", "iconUrl": "https://example.com/icon.png" }. The creator becomes owner, and backend auto-creates a default general channel.

GET /guilds/:guildId fetches guild detail, members, and channels.

GET /guilds/:guildId/channels fetches channels in a guild.

POST /guilds/:guildId/channels creates a channel. Body: { "name": "general-chat", "type": "text", "position": 1 }. Only owner or admin can create channels.

POST /guilds/:guildId/leave lets current user leave a guild. Owner cannot leave yet.

GET /channels/:channelId/messages?limit=50 loads channel messages.

POST /channels/:channelId/messages sends a channel message as REST fallback. Body: { "content": "Hello" }. This route is limited to 10 messages per minute.

Use Socket.IO for realtime chat. Connect like this: io(VITE_API_BASE_URL, { auth: { token: accessToken } }).

Socket events:

Emit channel:join with { channelId } when opening a channel.
Listen to channel:joined.
Emit channel:message:send with { channelId, content } when sending a message.
Listen to channel:message:new and append the new message to the active channel messages.
Listen to channel:error and display error.message.
Frontend flow:
After login, store the access token. On app load, call GET /guilds. When user selects a guild, call GET /guilds/:guildId or GET /guilds/:guildId/channels. When user selects a channel, call GET /channels/:channelId/messages?limit=50, then emit channel:join. When user sends a message, prefer Socket.IO channel:message:send; if socket is disconnected, fallback to REST POST /channels/:channelId/messages. Do not refetch all messages after every new message; append channel:message:new to local state.
