Fix the DM voice call socket emit flow.

Use exact event name: "call:invite". Do not use "call:onvite" or "call:invited" when starting a call.

When caller clicks call button, emit "call:invite" with acknowledgement callback:

socket.emit("call:invite", { conversationId }, (ack) => {
  console.log("[Call] invite ack", ack);

  if (!ack?.success) {
    const message = ack?.error?.message ?? "Failed to start call";
    console.error("[Call] invite failed", ack?.error);
    showError(message);
    cleanupCallState();
    return;
  }

  const payload = ack.data;
  setCallId(payload.callId);
  setCallState("calling");
  setCallee(payload.callee);
});

Also still listen to backend events:

socket.on("call:invited", (payload) => {
  console.log("[Call] invited", payload);
  setCallId(payload.callId);
  setCallState("calling");
  setCallee(payload.callee);
});

socket.on("call:delivery", (payload) => {
  console.log("[Call] delivery", payload);
  // If payload.delivery.onlineRecipientSocketCount is 0,
  // backend did not see receiver online.
});

socket.on("call:incoming", (payload) => {
  console.log("[Call] incoming", payload);
  setIncomingCall(payload);
  openIncomingCallModal();
});

socket.on("call:error", (error) => {
  console.error("[Call] error", error);
  showError(error.message);
  cleanupCallState();
});

Important:
- Caller emits "call:invite".
- Caller receives ack and "call:invited".
- Receiver receives "call:incoming".
- If ack.success is false, backend rejected the call invite and frontend must show ack.error.message.
- If ack.success is true but receiver sees nothing, check "call:delivery".
